# Capability Model

The Capability Model describes what an adapter can expose to LunaAgentOS.

## Capability groups

- Runtime session lifecycle.
- Streaming events.
- Resume and load session.
- Tools.
- Models.
- Skills.
- MCP servers and resources.
- Profiles and runtime targets.
- Permissions and approvals.
- Routing metadata.

Capabilities let the App show a coherent control experience while preserving each agent product's native strengths.
