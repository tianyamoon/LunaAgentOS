# Trademark and Brand Guidelines

[中文](./TRADEMARKS.zh-CN.md)

This document explains the relationship between the LunaAgentOS code license and the LunaAgentOS name, logo, and brand identifiers.

## Code license

The source code in this repository is licensed under [Apache-2.0](./LICENSE), except where a file clearly states otherwise.

Apache-2.0 gives permissions for the covered code under its own terms. This trademark document does not narrow, replace, or add restrictions to those code-license permissions.

## Brand rights

The LunaAgentOS name, logos, word marks, icons, visual identity, and other brand identifiers are not automatically licensed for unrestricted trademark use by Apache-2.0.

Using, copying, modifying, distributing, or forking the code does not by itself grant permission to use the LunaAgentOS brand in a way that suggests endorsement, official status, or source identity for another product or service.

## Acceptable uses

You may use the LunaAgentOS name in a truthful, non-confusing way to:

- refer to the original LunaAgentOS project
- link to this repository
- describe compatibility with LunaAgentOS
- explain that your work is based on, derived from, or forked from LunaAgentOS
- retain required license notices and attribution for redistributed code

These uses should not imply that your project, product, package, adapter, service, or distribution is official, endorsed, or maintained by the LunaAgentOS maintainers unless that is explicitly true.

## Uses that need permission

Please ask for permission before using LunaAgentOS names or logos to:

- name a separate product, company, package, service, organization, or domain
- present a fork or modified distribution as official LunaAgentOS
- use the logo or visual identity as the primary branding for another project
- create merchandise, promotional material, or commercial branding around the LunaAgentOS marks
- imply endorsement, partnership, certification, or maintainer approval

## Forks and modified versions

Forks and modified distributions should use their own name and branding. They may state that they are based on LunaAgentOS, as long as that statement is accurate and does not confuse users about who maintains the fork.

If you substantially change behavior, security posture, release process, or compatibility, make that clear to users.

## No change to Apache-2.0 rights

This document is about trademark and brand use only. It does not prevent anyone from exercising rights granted by [Apache-2.0](./LICENSE) for the covered code, including using, copying, modifying, merging, publishing, distributing, sublicensing, or selling copies of the code under the license terms.

## Questions

If you are unsure whether a use is acceptable, open a minimal public issue asking for a contact path or clarification. Do not include confidential business details in a public issue.
