# LunaAgentOS Apps

Apps are the concrete product experiences built on the LunaAgentOS protocol, adapter host, and Runtime Session Model.

## Official App

- [`desktop-shell/`](./desktop-shell/) is the protocol's concrete control console and the official recommended way to use LunaAgentOS today.

The App turns heterogeneous runtime sessions into a visible workspace: Agent Fleet, Runtime Session Cards, live sessions, archived history, runtime probing, and local control.
