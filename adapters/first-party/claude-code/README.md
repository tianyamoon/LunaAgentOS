# Claude Code Adapter

Claude Code is a first-party LunaAgentOS adapter for high-value coding workflows.

## Runtime surface

- Surface: `acp_stdio`
- Hosts: Windows and WSL
- Target kind: runtime

## Product role

Claude Code validates the Runtime Session Model against long-form coding output, tool activity, Markdown-heavy responses, and resumable sessions.

The App presents Claude Code as a real runtime target in the Agent Fleet and renders its turns through Runtime Session Cards.
