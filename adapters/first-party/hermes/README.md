# Hermes Adapter

Hermes is a first-party LunaAgentOS adapter for profile-based coding-agent runtimes.

## Runtime surface

- Surface: `acp_stdio`
- Hosts: Windows and WSL
- Target kind: profile

## Product role

Hermes validates Runtime Session visibility for profile metadata, process events, thought streams, tool activity, plan updates, usage updates, and WSL runtime routing.

The App presents Hermes profiles as concrete runtime targets and keeps profile identity visible in Runtime Session Cards and history.
